Magic link auth via Cloudflare Worker
Enter email → get a link → click → signed in. No passwords.
▾

Worker generates a time-limited token, stores it in D1, sends an email via Gmail Apps Script (same system as Phase 1). User clicks link → Worker validates token → sets a session cookie → they're in. Lowest friction for this audience.
